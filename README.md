Ця програма створена для того, щоб проаналізувати текст, який вводить користувач. Вона зчитує повний рядок, розбиває його на окремі слова (ігноруючи пробіли, табуляцію та символи нового рядка), 
а потім рахує, скільки разів кожне слово зустрічається. Для цього використовується словник (map), де кожне слово зберігається як ключ, а кількість повторень — як значення. 
Після обробки програма виводить список усіх унікальних слів разом із кількістю їх появ у введеному тексті. Це зручно для підрахунку частоти слів у простому тексті.
